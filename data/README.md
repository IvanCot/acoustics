# Собственные данные

Данные изначально отсутствуют. Приложение ничего не обучает на искусственных звуках автоматически.

Структура: `data/{train,test,demo}/{wood,metal,other}/{session_id}/file.wav` (также MP3).
`wood` и `metal` — стуки по известному материалу. `other` — речь, музыка, фон, ветер и записи без удара: отрицательные примеры детектора стука. WAV с тишиной допустим в `other`, пустые байты и повреждённые файлы — нет.
Модель 1 обучается на стуках и `other`, модель 2 — только на дереве/металле. Анализ переключается между каскадом 1 → 2 и прямой моделью 2. `demo` исключён из обоих обучений и оценок.
Сессия — отдельный сбор данных для обоих классов; её ID не должен встречаться в другой выборке.
Добавляйте файлы через интерфейс или копируйте в эти папки и нажимайте «Обновить с диска».
Записи хранятся локально и исключены из Git. Не добавляйте конфиденциальное аудио.

Полный протокол: [docs/RECORDING.md](../docs/RECORDING.md).

Текущий локальный набор: ручные wood/metal и отрицательные примеры ReaLISED (speech, television, water, vacuum cleaner; CC BY 4.0, https://doi.org/10.5281/zenodo.6488321). Реестр: `realised_negative_manifest.csv`. Проверка `val` сохранена в `artifacts/gate-validation.json`, финальный `test` пока не оценивался. Источники положительных и отрицательных примеров различаются, а независимость сессий не подтверждена.
