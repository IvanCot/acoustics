# Данные модели и выбор подхода

Проверено по первичным страницам 16 октября 2026 года. Внешние данные и модели не скачаны, не прослушаны целиком и не использованы приложением. Ниже подтверждено содержание по описаниям авторов и опубликованной схеме классов; доступность всех архивов и качество на наших записях не подтверждены.

## Открытые данные

Вывод: подходящие исследовательские записи существуют. Для MVP за два дня выбираем собственные записи: меньше подготовки, известное происхождение, прямое соответствие условиям демонстрации. Не утверждаем, что проверка на открытом корпусе выполнена. Загрузка одного архива и случайное разбиение фрагментов не доказывают обобщение.

## Предобученные модели

[YAMNet, официальное руководство](https://www.tensorflow.org/hub/tutorials/yamnet) — MobileNet на 521 событие AudioSet, вход моно 16 кГц, выходы scores и embeddings. В [официальной карте классов](https://github.com/tensorflow/models/blob/master/research/audioset/yamnet/yamnet_class_map.csv) есть Knock, Tap, Wood, Clang; пары классов wood/metal как классификатора материала нет. Heavy metal — музыкальный жанр. «Clang = металл» — неподтверждённое правило: форма, опора и ударник меняют звук.

[Исходный код YAMNet](https://github.com/tensorflow/models/tree/master/research/audioset/yamnet) и [Apache 2.0 репозитория](https://github.com/tensorflow/models/blob/master/LICENSE) доступны; лицензию конкретного скачиваемого артефакта весов необходимо проверить в его model card. Можно сравнить эмбеддинги YAMNet + собственный линейный классификатор с MFCC, заморозив веса и соблюдая то же разбиение. Это дополнительная установка TensorFlow и весов, не встроенная функция MVP. Прямой готовой модели с подтверждённым качеством на нашей паре материалов и наших коротких стуках в проведённом поиске не установлено. Это не утверждение, что таких исследований вообще нет.

## Внешний API и локальная модель

В качестве конкретного API рассмотрен Gemini: официальная [документация аудиовхода](https://ai.google.dev/gemini-api/docs/audio) подтверждает анализ аудио и текстовые ответы, но не даёт измеренного качества различения материалов по стуку. Возможность описать звук не означает надёжность классификации. Вывод по материалу остаётся гипотезой до проверки на нашей выборке.

| Критерий | MFCC + LogReg, реализовано | YAMNet embeddings + классификатор | Gemini API, только сравнение |
|---|---|---|---|
| Именно дерево / металл | Обучается на наших метках; реальное качество нужно измерить | Своих меток всё равно требует; преимущество не измерено | Нет подтверждённого профильного качества |
| Реализация за два дня | Библиотеки уже есть, фиксированный базовый алгоритм | Дополнительные зависимости и загрузка весов | Нужны аккаунт, ключ, настройка запроса и проверка ответа |
| Интернет / ключ | Не нужны после установки библиотек | Интернет для первоначальной загрузки; ключ локальному инференсу не нужен | Нужны сеть, ключ и доступный регион/проект |
| Стоимость / лимиты | Нет платы за запрос, ресурсы компьютера | Нет платы за локальный запрос, ресурсы компьютера | Оплата по токенам; бесплатная квота и лимиты зависят от модели и проекта |
| Приватность | Обработка на компьютере | Обработка на компьютере после загрузки весов | Аудио передаётся провайдеру; условия зависят от тарифа |
| Демонстрация без сети | Работает локально | Возможна после установки и кеширования весов | Невозможна без отдельного локального пути |
| Объяснение жюри | Собственные train/test, фиксированные признаки, матрица ошибок | То же разбиение + описание предобучения | Нужны тот же test, версия модели, промпт и журнал ответов; API сам не заменяет проверку |

По [официальному прайсу](https://ai.google.dev/gemini-api/docs/pricing), для **Gemini 3.1 Flash-Lite, Standard** на дату проверки: аудиовход **$0.50 / 1 млн токенов**, текстовый выход **$1.50 / 1 млн токенов**, текстовый вход $0.25 / 1 млн токенов. Цена не фиксируется за файл: итог зависит от фактических токенов. Бесплатный уровень указан на странице, но его доступность и величина квот для вашего проекта не проверены. [Лимиты](https://ai.google.dev/gemini-api/docs/rate-limits) зависят от уровня и модели; не обещаем конкретное число запросов без аккаунта.

[Условия Gemini](https://ai.google.dev/gemini-api/terms) допускают использование содержимого бесплатного сервиса для улучшения продуктов и обработку людьми; прямо запрещают отправлять туда конфиденциальные данные. Условия платного уровня отличаются; обязательства хранения и допустимость конкретного аудио следует проверять отдельно. В прототипе нет интеграции API, ключей, телеметрии и отправки аудио в облако.

Рекомендация: завершить собственный эксперимент на MFCC. Только если останется время, отдельно сравнить замороженные YAMNet-эмбеддинги. Если выбирать вариант по test, этот test становится валидацией — финальное качество тогда измерять на ещё одной новой выборке. API не нужен для выполнения кейса и добавляет зависимость демонстрации от сети.
