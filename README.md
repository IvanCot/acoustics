# Акустический детектив

**Локальное приложение, которое по звуку удара проверяет, похож ли он на стук, и определяет вероятный материал: дерево или металл.** Для работы достаточно компьютера с Python и браузера; аудиозаписи не отправляются во внешние сервисы.

## Как пользоваться

1. Запустите приложение по инструкции ниже и откройте `http://127.0.0.1:8765`.
2. Выберите режим **«С проверкой стука»** для проверки стука с последующим определением материала или **«Сразу материал»**, чтобы сразу получить один из двух классов.
3. Загрузите WAV/MP3. Можно выбрать несколько файлов: они обрабатываются последовательно, а прогноз, отказ и ошибка для каждого файла выводятся отдельной строкой.

Если в записи несколько отдельных ударов, включите **«Несколько стуков»**. Этот режим работает с обоими вариантами анализа: для каждого найденного удара появляются время, результат и кнопка просмотра аудио и графиков. Для первого использования делайте отчётливые удары с паузами от 0,5 секунды; длительность файла — до 10 секунд. Используются уже обученные модели.
4. Откройте подробный результат, чтобы прослушать обработанный фрагмент и увидеть форму волны, спектрограмму и оценки классов.

Раздел **«Данные и обучение»** позволяет добавлять дерево, металл и неподходящие звуки, разделять записи на обучающие, проверочные и отложенные выборки и переобучать одну или обе модели. Раздел **«Проверка качества»** строит матрицу ошибок, accuracy, balanced accuracy, macro F1 и сводку отказов детектора.

## Как устроено распознавание

```text
Аудио → проверка формата и уровня сигнала → моно, 16 кГц → мягкое шумоподавление
  Модель 1: вся запись → «стук / неподходящий звук»
  Модель 2: фрагмент около удара → «дерево / металл»
```

Обе модели — независимые логистические регрессии scikit-learn с отдельной стандартизацией признаков. Детектор описывает полную запись 42 спектральными и временными признаками. Классификатор материала анализирует двухсекундный фрагмент около удара и 39 акустических признаков, включая MFCC и затухание. При обучении к каждому train-файлу добавляются две воспроизводимые вариации громкости и слабого шума. Исходные аудиофайлы не изменяются.

В текущем наборе 156 подготовленных WAV: 78 стуков (38 деревянных и 40 металлических) и 78 неподходящих звуков. В `train` — 54 стука (26 деревянных и 28 металлических) и 54 неподходящие записи. При двух дополнительных вариантах на запись это 162 примера для классификатора материала и 324 для детектора стука. После замены металлических записей сохранённые модели в `artifacts/` требуют переобучения; прежние отчёты оценки относятся к старому составу данных. Состав данных и атрибуция ReaLISED описаны в [THIRD_PARTY.md](THIRD_PARTY.md).

## Результаты и ограничения

До замены металлических записей прежняя версия показала 24/24 на валидации; при дополнительном белом шуме с SNR 20 дБ вариант с аугментацией дал 23/24, а обучение без аугментации — 21/24. Эти результаты относятся к предыдущему составу данных. После переобучения заново запустите проверку на `val`, а затем итоговую оценку на `test`.

Эти числа не доказывают качество на независимых записях. Разбиение ручных аудиофайлов выполнено по отдельным файлам, а не по независимым сессиям; фоновые примеры ReaLISED записаны в других условиях и отдельно не прослушивались. Различия микрофонов могут влиять на прогноз. Для оценки обобщения нужны новые записи дерева, металла и неподходящих звуков с других сессий и устройств. Отчёт по `test` следует запускать после обучения актуальных моделей в разделе «Проверка качества».

Шумоподавление мягкое: оно оценивает фон по тихим кадрам и ограничивает подавление примерно 3,7 дБ; если фон неотличим от основного события, фильтр пропускает запись без изменений. Сильный шумодав намеренно не используется, чтобы сохранить звон и затухание стука.

Детектор может пропустить незнакомый звук, а в режиме «Сразу материал» любая подходящая по формату запись получает оценку дерева или металла. Баллы моделей не калиброваны как вероятности. Результат зависит от предмета, точки и силы удара, опоры, микрофона и помещения. Приложение не диагностирует дефекты и не заменяет профессиональную оценку изделия.

## Запуск

Нужен Python 3.10 или новее. В PowerShell, Windows Terminal или командной строке:

```bash
git clone https://github.com/IvanCot/acoustics.git
cd acoustics
python -m pip install -r requirements.txt
python server.py
```

Откройте `http://127.0.0.1:8765`. Остановка сервера — `Ctrl+C`. Сервер слушает только локальный компьютер. Чтобы запустить проверки разработчика:

```bash
python -m unittest discover -s tests -v
```

## Структура проекта

- `server.py` — локальный HTTP-сервер и API.
- `acoustic/audio.py` — декодирование, шумоподавление и извлечение признаков.
- `acoustic/experiment.py` — набор данных, обучение, прогноз и отчёт по проверке.
- `web/` — адаптивный русскоязычный интерфейс без внешних CDN.
- `data/{train,val,test,demo}/` — аудиозаписи, включённые в репозиторий.
- `artifacts/` — обученные модели и отчёты в JSON.
- `docs/RECORDING.md` — рекомендации по записи аудио; `docs/RESEARCH.md` — обзор альтернативных моделей и наборов данных.
